Help & troubleshooting

常见问题与使用帮助

连接、权限或下载安装遇到问题？先看看这些常用排查步骤。

如何连接两台电脑？

两台电脑安装并启动 Lantern，确保它们在同一个局域网。在被控端点击“启动被控端”，然后在控制端添加被控端显示的局域网 IP（端口可省略，默认 4200），再连接并在被控端批准。防火墙需允许 TCP 4200 及 UDP 4201–4210。

连接失败或一直没有画面，应该检查什么？

确认两台设备处于同一网络且没有访客网络隔离；确认被控端 Lantern 正在运行，并允许 TCP 4200 和 UDP 4201–4210 通过防火墙。部分路由器的无线客户端隔离会阻止设备互通。还可以先重启两端应用，再试一次。

Lantern 需要账号、云服务或互联网吗？

当前连接面向局域网，不需要 Lantern 账号，也不通过 Lantern 云端中转。首次连接需要被控端批准；仅在你信任的网络中使用，不要将通信端口暴露到互联网。屏幕与键鼠数据通过 WebRTC 加密传输。

macOS 为什么看不到屏幕或不能操作？

请在“系统设置 → 隐私与安全性”中为 Lantern 开启“屏幕录制”和“辅助功能”权限。修改权限后可能需要完全退出并重新打开应用。详细说明见 系统权限文档。

Windows 上某些游戏或管理员窗口不能控制怎么办？

独占全屏、Raw Input、管理员权限隔离及反作弊保护可能会拒绝普通桌面输入。可以尝试窗口化/无边框模式，并让两端应用以相同权限级别运行。Lantern 不会绕过反作弊或安全桌面保护。

关闭窗口后，Lantern 还会继续运行吗？

桌面版默认将窗口隐藏到系统托盘，远程服务继续运行。托盘菜单可以重新显示窗口或退出应用；也可以在应用设置中将关闭行为改为彻底退出。Linux 托盘图标是否显示取决于当前桌面环境是否提供托盘支持。

主页需要在每次发布新版本时手动更新吗？

通常不需要。主页下载按钮会指向 GitHub 的最新 Release 页面，版本发布工作流会把各平台安装包作为 Release 制品上传。Release 会持续保留，除非维护者删除；Actions 运行中的临时制品则会在 14 天后过期。也可在 所有 Releases 中选择历史版本和平台。

在哪里报告问题或查看已知问题？

请在 GitHub Issues 搜索已有问题，或提交新 Issue。请注明应用版本、操作系统和复现步骤；发布日志也可以帮助定位。不要在公开 Issue 中粘贴密码、私密文件或其他敏感信息。
